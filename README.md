# Tic Tac Toe

A polished, responsive Tic Tac Toe game built with plain HTML, CSS, and JavaScript.

## Features

- 3x3 interactive game board
- Two-player alternating turns for X and O
- Turn, win, draw, and game-over messaging
- Move validation to prevent overwriting occupied cells
- Winning cell highlight
- Persistent score tracking until the page is refreshed
- Responsive layout for desktop and mobile
- New Game button to reset the board instantly

## Run locally

Because the project uses only static files, you can run it with any local web server.

### Option 1: Open directly

Open `index.html` in your browser.

### Option 2: Serve with Python

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
